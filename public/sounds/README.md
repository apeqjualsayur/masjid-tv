# Sounds for the TV sound cues

Put `hayya-ala-solah.mp3` here (mono, ≤ 300 KB, no silence at the start).

It is the owner's own recording of "Hayya 'alas solah", used by the `hayya` cue
(`_specs/50-PRD-sound.md` D3). It is played whole; a file longer than 20 s is cut at
20 s with a short fade. Never generate or download voice audio for this folder.

If the file is missing or cannot be decoded, the TV plays the chime instead.
Every file here (except this README) is precached by the service worker, so the
cue also plays offline.
