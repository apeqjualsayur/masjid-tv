## S0 — You: preparation (about 45 minutes)

1. Copy `70-PRD-seo.md`, `71-seo-prompts.md`, `72-articles-content.md` from the Project into `masjid-tv/_specs/`.
2. Terminal: `git checkout main && git pull && git checkout -b seo` then `git add -A && git commit -m "specs: seo"`.
3. **Google Search Console** (search.google.com/search-console) → Add property → **Domain** → `masjidview.my` → copy the TXT record → Cloudflare dashboard → masjidview.my → DNS → Add record (Type TXT, Name `@`, Content = the value) → back in Search Console press Verify. Then Sitemaps → submit `https://masjidview.my/sitemap.xml`.
4. **Bing Webmaster Tools** (bing.com/webmasters) → sign in → **Import from Google Search Console** → choose masjidview.my.
5. **Cloudflare**:
   - Web Analytics → add site `masjidview.my` (for a Pages project it can be turned on from the project's Metrics tab).
   - Caching → Configuration → **Crawler Hints** → On.
   - Search the dashboard for **"AI Crawl Control"** / **"Block AI bots"** / **"Manage robots.txt"**. Make sure AI bots are **not blocked** on masjidview.my and Cloudflare does not replace your robots.txt. Take a screenshot of what you see if unsure and send it to Claude.
6. **Baseline:** run the 4 questions in PRD §9 in ChatGPT, Gemini, Perplexity and Copilot. Note mentioned / linked / correct in a sheet. In Search Console, note how many pages are indexed (it may take 2–3 days to show data).
7. **Decisions** (PRD §4): D1 who is named on the About page; D2 Facebook / YouTube links if they exist. If you change a default, edit the table in `_specs/70-PRD-seo.md` before S1.
